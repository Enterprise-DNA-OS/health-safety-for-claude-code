---
description: Toolbox talks per site - who has gone quiet, what was covered - and recording this morning's talk in one command.
---

1. Run `npm run safety -- toolbox` for the last talk per site, or `--site=` for one site's history.
2. A site quiet past a fortnight is on the attention list and fails `/compliance` (worker engagement is a duty: HSWA ss 58-61). The fix is a talk, not a memo.
3. The best topic is on today's attention list: the incident just closed, the hazard whose control changed, the ticket about to expire. Offer the operator the top item as the talk.
4. Record it the same morning: `npm run safety -- talk "<site>" --topic="..." --by= --attendees=N`.
5. If the operator wants talk material, write half a page to `drafts/` from the record: what happened (facts from the incident card), what changed, the one behaviour asked for this week. Never invent an event.
